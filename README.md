# 🎁 Birthday Gift

A tap-to-open birthday gift animation in a single HTML file.

1. **Tap once** – the ribbon unties and the bow flies off.
2. **Tap again** – the lid pops off.
3. A flower bouquet blooms out of the box with confetti, falling petals and a music-box "Happy Birthday".

Open `index.html` in any browser (works on phones too).

## Personalise it

Add a name and message to the link:

```
index.html?name=Ava&msg=Love you lots!
```

The tag on the box and the greeting will use the name, and your message shows under the bouquet.
